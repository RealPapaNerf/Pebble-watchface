# Store listing

Name: **Simply Digital**

Category: Daily

Platform: Pebble Time 2 (Emery)

## Short description

A monochrome seven-segment clock with Health data and local sun times.

## Description

Simply Digital combines a large retro seven-segment clock with a clean
black-and-white LCD layout, crisp pixel function labels, a bold pixel weekday,
a reversed time-format indicator, and a rounded frame. It follows the watch's
12/24-hour setting and displays the localized weekday and date with year.

See battery charge, daily steps, current heart rate, sunrise and sunset at a
glance. Large status values sit beside fixed label-and-icon columns; long values
automatically use a smaller font. Missing values remain in fixed positions as
dashes. The clock updates once per minute. There are no settings, accounts,
ads or analytics.

Health data stays on the watch. Sun times are calculated locally with SunCalc
1.9.0, normally once per day, without web requests. Coordinates are not stored
by the app. The phone's location provider may use GPS, Wi-Fi or cellular
services. Sun times require a paired phone and location permission; they are
approximate and may retain an earlier location until the next day. On days
without both sun events, the fields show dashes. The clock works without
location access.

Independent watchface; not an official Casio, Pebble or Core Devices app.
Developed with the assistance of coding AI.

## Release notes — 1.0.0

Initial Pebble Time 2 release with a large seven-segment clock, crisp pixel
